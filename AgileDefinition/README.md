# Agile Definition Seed

This folder contains an editable agile backlog initialization for the SN Workout project.

## Files

- `PROJECT_CONTEXT.md`: distilled project context taken from workspace instructions.
- `epics.csv`: epic-level backlog.
- `stories.csv`: story-level backlog with required story fields.

## Editing

- Open `epics.csv` and `stories.csv` in Excel, Google Sheets, or VS Code.
- Keep the `epic_id` values stable so stories stay linked to epics.
- For `acceptance_criteria`, `validation_plan`, and `technical_solution`, use ` | ` to separate multiple items.

## Story Field Contract

Each story includes:

- `title`
- `epic_id`
- `description`
- `acceptance_criteria`
- `validation_plan`
- `technical_solution`
